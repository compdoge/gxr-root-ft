Dilation range -

Learned range
-
VRCFT normalizes pupil dilation against this range, so it sets how much movement the avatar shows. The relay learns it from clean frames and remembers it across restarts. Type your own min/max and press Use these values to skip calibration entirely - that writes both numbers and locks them. Lock freezes the learned range (the usual choice once it has settled, and the fix for one stray reading squeezing it); Unlock lets it adapt again after a big change in light level; Reset forgets it and learns from scratch.

Developer options

Optional sender tuning. Values are passed straight to gxr_alvr; a field left at its default is omitted. PC IP, port, TongueRoll and Verbose live in Connection.

Advanced — firmware probes (change only if your firmware differs)
